# Floating Action Button — implementation specification

Status: ready

Figma: [FAB section](https://www.figma.com/design/BsQQUym4xOYfOs419MpBBX/Components-%7C-Dopamine-2.0?node-id=4023-2838&t=2b3pGoo58LPx32e2-4).

The component supports Figma `Add`, `Added`, `FAB`, and `Special button` variants, with `Default`, `Disable`, and `Single Added` states. Frame sizes are 32px (Add), 56×28px (Added), 40px (FAB), and 81×24px (Special button). Icon-only actions receive an accessible name.
