# Patterns

Patterns are composed recipes — several components wired together to solve a
whole task (an OTP screen, a filter sheet, a checkout row). They sit one level
above components: components are the vocabulary, patterns are the sentences.

This tier is reserved and authored separately. Individual pattern pages will
appear here as they land, and the MCP (`list_patterns` / `get_pattern_docs`)
serves the same set to coding agents.
