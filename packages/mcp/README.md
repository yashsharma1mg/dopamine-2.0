# @dopamine2.0/mcp

MCP server that lets any Claude surface **discover, document, and preview** Dopamine2.0 UI. It
serves the generated registry + knowledgebase + tokens + prerendered component previews, so an
agent can look up exact props/variants/tokens and render a component before writing code.

Ships two ways from one `npm run build` (at the repo root), both serving the **same 10 tools** from
the same generated source of truth:

- **Local stdio package** — `dist/index.js` + bundled `data/` (self-contained, runs anywhere).
- **Remote HTTP endpoint** — `app/mcp/route.ts` on the design-system Cloudflare Worker (`/mcp`).

## Tools

| Tool | Returns |
|---|---|
| `list_components` | Catalogue (name, category, status, summary). |
| `search_components(query)` | Best matches by intent/keywords. |
| `get_component_docs(name)` | Real props (from TypeScript), variants/states, do/don't, a11y, example. |
| `list_patterns` / `get_pattern_docs(name)` | Composed multi-component recipes. |
| `get_general_docs(topic)` | install · theming-tokens · conventions. |
| `get_tokens(category?)` | Design token values. |
| `get_agent_rules` | AGENTS.md rules to drop into a consuming project. |
| `preview_component(name)` / `preview_pattern(name)` | Self-contained HTML render (view as an artifact). |

## Add it to Claude

**claude.ai web / Desktop (remote):** add `https://<site>/mcp` as a custom connector. Gate it with
a bearer token — `wrangler secret put MCP_TOKEN` on the Worker, then send
`Authorization: Bearer <token>`. Unset ⇒ `503` (secure by default).

**Claude Desktop (local):** `claude_desktop_config.json` →
`{ "mcpServers": { "dopamine2": { "command": "node", "args": ["/abs/.../packages/mcp/dist/index.js"] } } }`

**Claude Code:** `claude mcp add dopamine2 -- node /abs/.../packages/mcp/dist/index.js`
(auto-discovered via repo `.mcp.json` inside this repo).

## Architecture

`src/tools.ts` holds the pure tool logic (`TOOL_DEFS` + `createHandlers(data)`) with **no fs, no
transport, no SDK** — the data is injected. `src/index.ts` (stdio) feeds it via `src/data.node.ts`
(bundled `data/`); `app/mcp/route.ts` (edge) feeds it via `app/mcp/data.edge.ts` (one
`edge-bundle.json` import) and dispatches JSON-RPC by hand. The `data/` directory and
`edge-bundle.json` are generated by `scripts/bundle-mcp.mjs` + `scripts/prerender-previews.mjs`
from the same files `scripts/generate-registry.mts` emits — so nothing drifts.

## Dev

- Run from source (no build): `npm start` (`tsx src/index.ts`).
- Build the package: `npm run build` (`tsc` → `dist/`). The repo-root `npm run build` also copies
  `data/` and prerenders previews.
